## Original generation prompt (before the user-provided crop)

Use case: ui-mockup
Asset type: wide GitHub README hero banner, roughly 2.4:1 landscape.
Primary request: A beautiful schematic illustration of our Apple device HTML prototyping simulator, a reusable developer layout workbench.
Composition: crisp editorial technical illustration on warm ivory paper, very subtle dot grid. Three device viewport outlines arranged across the banner: a narrow portrait phone at left; a large landscape tablet centered and dominant inside a minimal desktop browser workbench; a folded tabletop device at right in restrained isometric perspective with content on the upper half and a few control pills on the lower half. The central browser has a slim left inspector with simple swatches and slider strokes and a large preview stage. In every viewport show the same abstract interface made of a blue circular orb, rounded cards, small glass toolbar pills and a few understated text-like rules. Use thin blue dashed safe-area guides inside the central viewport, fine dimension arrows outside it and a small fold seam on the tabletop. Content extends to screen edges; safe-area guides are diagnostic lines, never huge empty bands.
Style: sophisticated vector-like schematic illustration, precise linework, restrained soft shadows and translucent glass accents. Ink navy outlines, electric periwinkle blue accent, soft teal touches. No photographs, no glossy 3D product advertising.
Text: no words, no letters, no numbers. The README supplies the title.
Constraints: generous breathing room, legible at GitHub README width, keep every device fully in frame, no Apple logo, no book or frog imagery, no watermark. This is a conceptual layout workbench illustration, not a claimed native iOS screenshot. Save a polished finished hero image.
